详情（复制下面整段）
----
原创 Jetson YOLO 部署包，不是网盘搬运。

你买到的是脚本和步骤，不是现成商业模型。
自备 yolov8n.pt 或自己训练的 pt 即可。

包含：
1. 一键检查 JetPack / CUDA / TensorRT / 摄像头
2. pt 转 TensorRT engine（FP16 / INT8）
3. 实测 FPS 脚本（在板子上测，不拿电脑数字充数）
4. USB 摄像头实时画框
5. ROS2 节点：订相机话题，发带框图
6. 12 条常见报错对照（engine 不能跨板、掉帧、INT8 崩精度等）

适合：
Jetson Orin Nano / NX / Xavier
YOLOv8 / 同系列 Ultralytics 导出
ROS2 Humble 想把检测接到相机话题

不适合 / 不包含：
不代写作业、不包过、不含第三方权重
Windows 一键包没有（脚本按 Jetson 来）
不保证某一款自训模型的 mAP

怎么用：
解压后看 README.md，10 分钟按命令跑。
拍下后发网盘链接，提取码另发。

售后：
虚拟资料发出不退。
脚本命令跑不通，把完整报错发我，24 小时内告诉你卡在哪一步。
不包远程桌面、不包改你公司业务代码。
